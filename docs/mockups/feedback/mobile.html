Why a bottom sheet, not a modal?

On mobile, a modal centered on-screen loses page context and the user's thumb has to reach across the viewport. A bottom sheet stays in thumb-reach and keeps the page visible behind it — Material 3 + NN/G consensus for short focused tasks.

Interaction notes for this surface

  • Tap megaphone → sheet slides up 0.28s, swipe handle visible.
  • Drag the handle down or tap the backdrop to dismiss.
  • Submit button is sticky above the safe-area, full-width, thumb-reach.
  • Screenshot picker opens native iOS/Android file UI; "paste image" hint surfaces because both Safari + Chrome on Android now support clipboard image paste in 2024+.
  • On success the form swaps to the inline ack (no toast) for ~2s, then sheet auto-dismisses.
