Which footer icon should we use?

Five outline + one solid candidate from Lucide (the icon family closest in style to the live site's footer SVGs). Each row shows the candidate placed in an exact-replica of the existing footer rail (using the real .footer + .footer-icon classes) so you can compare in context.

Recommendation: Megaphone — Lucide tags it "announcement, attention", the semantic valence closest to "issue or suggestion". Bug skews issue-only; flag reads as moderation; comment-bubble is too generic.
Megaphone Recommended
lucide / megaphone
tags: announcement, attention, broadcast
+ Semantic match: "broadcast a message to the team"
+ Unique silhouette: doesn't collide with any other footer icon
– Heavy: the densest of the six — may feel busy on small screens
Message-square-text
lucide / message-square-text
tags: chat, comment, reply
+ Familiar: most commercial feedback widgets default to this
– Generic: reads as "support chat", not "submit issue/idea"
– Outline weight: visually lighter than the existing solid icons — slight inconsistency
Bug
lucide / bug
tags: report, debug, defect, error
+ Strong "report a problem" signal
– Bug-only: discourages suggestions; user expectation diverges from the Suggestion tab inside
Flag
lucide / flag
tags: report, warning, mark
– Reads as "report abusive content": in 2024-2026, flag icons in user-facing chrome almost always mean moderation/reporting other users
– Wrong valence for "share an idea with the team"
Alert-circle
lucide / alert-circle
tags: alert, warning, error
– Reads as "system alert" not "user input"
– Close to the existing "About" (info) icon — high collision risk in the rail
Lightbulb
lucide / lightbulb
tags: idea, suggestion, hint
+ Strong "share an idea" signal
– Suggestion-only: discourages bug reports (mirror failure of the bug icon)
