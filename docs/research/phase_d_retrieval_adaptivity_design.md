## P2-4 — Query-adaptive dense/sparse/graph mixing (score-gap margin over static RRF)

> **Research outcome (APPROVED):** Shannon entropy was SUPERSEDED by a
> per-channel **score-gap margin** signal. Entropy needs a full normalized
> distribution per channel and a bin/temperature choice; the gap is a single
> top1/top2 ratio — cheaper, parameter-light, and trivially admits a
> float-EXACT identity proof. The design below is what was built.

- Static weights `_WEIGHTS_BY_CLASS` (sem,fts,graph) `hybrid.py:158-164`; `_weights_for_class` `:168-179` already has a `registry_adapter` override seam. The RPC payload weights (`p_full_text_weight`/`p_semantic_weight`, `hybrid.py:~590-592`) are sent BEFORE fusion and are **never touched** by P2-4. Python-side 3-source RRF fuse loop (k=60, `_RRF_K`), `hybrid.py:~1290-1305`.
- **Signal.** Per channel `c` (sem / fts / graph), take its ranked score list from the already-in-memory pre-fusion data — sem/fts from candidate `raw_dense_score`/`raw_fts_score` over `sem_rank_map`/`fts_rank_map` keys (`hybrid.py:1062-1093`), graph from the per-chunk mention-sum strength captured alongside `graph_rank_map` (`graph_strength_map`, built at the `anchor_chunk_mentions` aggregation `:~1120-1140`). Normalized gap: `gap_c = clamp01((s1 - s2) / (s1 + EPS))`, where `s1`/`s2` are the channel's top-2 scores. O(n), **no extra retrieval round**.
- **Modifier.** `m_c = clamp(1 + β·(gap_c − mean_present_gap), 1−Δ, 1+Δ)`; new weights `w_c' = (w_c·m_c)` then renormalized by `scale = Σw / Σ(w·m)` so **Σw' == Σw exactly**. Constants (module-level named): `_GAP_BETA = 0.25` (β), `_GAP_CLAMP_DELTA = 0.30` (Δ → modifier band `[0.70, 1.30]`), `_GAP_EPS = 1e-12`. A more-decisive-than-mean channel is up-weighted; a flatter one down-weighted. Single pass, no iteration.
- **HARD identity proof (float-EXACT, not approx).** `_gap_adapted_weights(weights, gaps)` returns the **same `weights` tuple object unchanged** (no arithmetic executes) whenever (a) the candidate pool is empty, (b) fewer than two channels carry a usable gap (a channel with <2 candidates yields `gap=None` and is excluded), or (c) all present gaps are equal (`max(present) == min(present)`). The modifier is applied ONLY to the in-Python RRF weight locals AFTER the RPC call and ONLY when `by_key` is non-empty. → degenerate / flat / empty cases produce `w_c' == w_c` byte-identical (zero regression vs today). Verified by `tests/unit/rag/retrieval/test_hybrid_phase_d.py` (`test_identity_when_all_gaps_none`, `test_identity_when_fewer_than_two_present`, `test_identity_when_all_present_gaps_equal` assert `out is _STATIC_THEMATIC`).
- **Composition.** K3 `_top1_top2_gap` (`hybrid.py:318-329`) reads the *post*-fusion `rrf_score` downstream and is unaffected — no semantic change to K3. The 3 RPC payload-weight regression tests are unaffected because the payload path is untouched.

## P2-5 — KG-aware retrieval for THEMATIC / MULTI_HOP

- `graph_score` (LIVE via Phase-A `rag.subgraph_for_pagerank`) is consumed only as a rerank fusion feature; `cascade._FUSION_WEIGHTS` UNCHANGED (no retune, no renorm risk) — proximity rides the existing `graph_score` channel.
- **Built:** CLASS-GATED to `QueryClass.MULTI_HOP` and `QueryClass.THEMATIC` only. In the PageRank normalization block (`graph_score.py:~128-160`, inside the existing `graph.number_of_edges() != 0` branch), `graph_score = clamp01(_PROX_PR_W·pr_norm + _PROX_W·prox_norm)` with named consts `_PROX_PR_W = 0.7`, `_PROX_W = 0.3`. `prox_norm` is `nx.degree_centrality` (normalized to [0,1] by n−1) over the **same in-memory `nx.Graph`** already built for PageRank — **NO new DB query**, reusing the single live `rag.subgraph_for_pagerank` result. The class is resolved from the existing `query_class` param (enum / str / None all handled).
- **All other classes (LOOKUP / VAGUE / STEP_BACK) → byte-identical** to pre-Phase-D: the else-branch assigns `candidate.graph_score = pr_norm` where `pr_norm = pagerank.get(node)/max_score`, the exact original expression. Cold graph / <2 nodes (`:83-86`) / 0-edge (`:124-126`) / RPC failure (`:103-113`) → `graph_score = 0.0` exactly as before (degrade contract preserved verbatim). Verified by `tests/unit/rag_pipeline/test_graph_score_v2.py` (`test_phase_d_ungated_classes_byte_identical_pure_pr` asserts exact equality with a re-implemented pre-change formula; cold/zero-edge/RPC-fail tests; `test_phase_d_no_extra_db_call_for_gated_classes` asserts exactly one subgraph RPC).
