## Working Memory Fundamentals
- Working memory is a limited-capacity system for holding information in mind for a goal.
- It requires attention and the neuromodulator dopamine.
- Its capacity is crucial for productive task-switching.

## Non-Diagnostic Working Memory Assessment
- Two non-diagnostic tests can provide a baseline proxy for working memory and dopamine levels.

### Test One (Number/Letter Recall)
- Involves recalling a string of numbers/letters.
- Results are categorized as low, moderate, or high.

### Test Two (Sentence Word Recall)
- Involves recalling one word from each of six sentences.
- 0-2 correct words indicate low working memory.
- 3-6 correct words indicate high working memory (3-4 is average).

## Neuroscientific Evidence: Dopamine and Working Memory
- Neuroimaging studies support a link between dopamine and working memory.
- D’Esposito et al. found individuals with high working memory spans have more dopamine available in the prefrontal cortex (PFC).
- Goldman et al. showed directly introducing dopamine into the PFC improved working memory.
- D'Esposito also showed drugs like bromocriptine, which increase dopamine, improve working memory in humans.

## Behavioral Tools for Working Memory Improvement
- Behavioral tools are recommended as a first-line approach.

### Non-Sleep Deep Rest (NSDR) / Yoga Nidra
- Practice of deliberate muscle relaxation.
- Can increase dopamine levels by up to 60% in key brain regions.
- Suggested frequency: 10-20 minute session, 2-3 times per week.

### Deliberate Cold Exposure
- 1-3 minutes in a shower or tub, 30-60 minutes before a work session.
- Can greatly increase dopamine, norepinephrine, and epinephrine for hours.
- Ideal temperature is individually determined, often 40-50°F (4-10°C).

### Binaural Beats (13-30 Hz)
- Showed mixed results in improving working memory during tasks.
- Studies by Engelbregt et al. and Beauchene et al. showed benefits.
- Mechanism of action is unknown.
- Effect may be greater for those with initially lower dopamine levels.

## Supplements for Working Memory (Consult a Doctor)
- Supplements should be used after behavioral tools and with a doctor's consultation.
- A 'crash' can occur with pro-dopamine supplements.

### L-tyrosine
- Starting dose: 500mg per 100kg body weight.

### Mucuna pruriens
- Contains 99% L-dopa, a potent precursor.
- Typical dose: 250-500mg, up to 1-5g for some.

## Prescription Drugs for Working Memory (Medical Consultation Required)
- Prescription drugs also improve working memory but require consultation with a board-certified MD.
- Examples include bromocriptine, Adderall, Ritalin, Vyvanse, or modafinil.
