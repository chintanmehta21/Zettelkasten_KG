## Features and modules

### Overview
- EconML is a Python package from a Microsoft Research project called ALICE (Automated Learning and Intelligence for Causation and Economics), now part of the PyWhy organization.
- It is designed for estimating heterogeneous treatment effects from observational data by combining machine learning with econometrics.
- The toolkit aims to measure the causal effect of treatment variables (T) on an outcome variable (Y), controlling for a set of features (X, W), and determine how that effect varies with X.
- Most methods provide confidence intervals and inference results, accessible via an `InferenceResults` object and a `summary()` method for linear models.
- Security vulnerabilities should be reported to the Microsoft Security Response Center (MSRC), not via public GitHub issues.

### Architecture / Modules
- The library provides a unified API for various methods.
- Methods include Double Machine Learning (e.g., `LinearDML`, `NonParamDML`), Dynamic DML, Causal Forests (`CausalForestDML`), Orthogonal Random Forests, Meta-Learners (`XLearner`, `SLearner`, `TLearner`), and Doubly Robust (DR) Learners.
- Supports instrumental variable (IV) methods (e.g., `OrthoIV`, `LinearDRIV`).
- Some methods assume no unobserved confounders, while others can use an observed instrument (Z).
- Includes tools for interpretability (e.g., `SingleTreeCateInterpreter`, SHAP values), causal model selection (`RScorer`), and policy learning (`DRPolicyTree`).

### Public API / Interfaces
- The library provides a unified API for various causal inference methods.
- Public surface: LinearDML, NonParamDML, CausalForestDML, XLearner, SLearner, TLearner.
